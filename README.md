# Filmpire

Watch free movies and TV shows on any Android device — phone, tablet, or Android TV.

## Download

[**Download Filmpire APK**](https://github.com/brian6870/FILMREPO/raw/main/Filmpire.apk)

## Features

- Pre-loaded with working providers (AllMovieLand, CinemaCity + 30+ sources)
- Android TV support with full remote navigation
- Phone and tablet layouts
- Video player with subtitles, quality selection, speed control
- Search, continue watching, library, downloads
- 30+ language translations
- Just install and start watching — no setup required
